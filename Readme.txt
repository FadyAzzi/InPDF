Reading
Continuous, single-page, facing and facing-continuous layouts. Zoom to page, width or a fixed level. Night mode inverts for reading in the dark. Read mode hides everything but the page. Thumbnails, bookmarks, comments and search results in the side panel; bookmarks can be renamed and dragged to nest into a hierarchy.

Editing
Click text to edit it in place, with font, size, bold, italic, colour and alignment changeable as you type. Move and resize images and objects. Add text boxes, signatures, one-click date stamps, pictures and clickable links, choosing what to insert first and then clicking where it goes.

Signatures
Draw, type or import a signature once and reuse it. Saved signatures can be renamed and deleted, and one stays loaded so you can initial every page of a contract without picking it again.

Comments and markup
Highlight, underline, strike through, squiggly underline, sticky notes, freehand pen and the 14 standard PDF rubber stamps. Export every comment as a text file that quotes the words actually marked, with page and line numbers. Flatten bakes markup into the page when a document is going out.

Shapes and measurement
Rectangles, ovals, lines, arrows, polygons and connected lines. Measure distance, perimeter, area and angle, calibrated against a length you know so readings come out in real-world units.

Pages and assembly
Rotate, duplicate, delete, extract, split, combine and crop. Insert blank pages or pages from another PDF. Add watermarks, headers and footers, page numbers, Bates numbering and page backgrounds, each reopenable from the History panel to adjust.

Protection
True redaction that destroys the content underneath rather than drawing a black box over it, by area or by searching for text. Password protection with separate open and permissions passwords. Strip metadata, attachments and scripts before sending a file out.

Conversion and comparison
OCR a scan with the engine built into Windows. Fill in forms. Compare two PDFs and get a report of what differs. Export to images, plain text, Word, HTML or CSV. Print.

Windows integration
Registers as a PDF handler so InPDF appears in "Open with" and in Settings > Default apps, with a button in Settings that takes you straight there. Drag a PDF onto the window to open it.
